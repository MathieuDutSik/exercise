• [1;32msrc/main.rs[0m: [32mcargo[0m [32mrun[0m [32m--[0m [32mtransactions.csv[0m [32m>[0m [32maccounts.csv[0m. It exits with code 2 if the arguments

[1mChoices[0m [1mthe[0m [1mspec[0m [1mleft[0m [1mopen[0m (also written up in [32mREADME.md[0m):

• A dispute, resolve or chargeback is ignored if its client doesn't match the client of the deposit
  it refers to.
• A dispute is rejected if the deposited money has already been withdrawn, so available funds can
  never go negative.
